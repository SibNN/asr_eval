# asr_eval ⚗️

Evaluation and building components for Automatic Speech Recognition in Python.

- [Preprint paper](https://arxiv.org/abs/2601.20992)
- [Full documentation](https://sibnn.github.io/asr_eval/)

<img src="https://sibnn.github.io/asr_eval/_images/showcase.png" width="100%" />

## Installation

Run `pip install asr_eval[all]` (see [installation guide](https://sibnn.github.io/asr_eval/guide_installation.html) for more details).

## Features

**🧪 Evaluation features** (see [overview](https://sibnn.github.io/asr_eval/overview_alignment.html),
[guide](https://sibnn.github.io/asr_eval/guide_alignment_wer.html)
and [reference](https://sibnn.github.io/asr_eval/asr_eval.align.html))

- Extended annotation syntax via multi-reference and wildcard blocks
- Aligned multiple model comparision with error highlighting

**⚙️ Benchmarking features** (see [guide](https://sibnn.github.io/asr_eval/guide_evaluation_dashboard.html)
and [reference](https://sibnn.github.io/asr_eval/asr_eval.bench.html))

- A set of baseline pipelines and datasets (in progress)
- Model benchmarking in scale with a web dashboard
- Components to build custom pipelines

**➰ Streaming features** (see [overview](https://sibnn.github.io/asr_eval/overview_streaming.html),
[guide](https://sibnn.github.io/asr_eval/guide_streaming_evaluation.html)
and [reference](https://sibnn.github.io/asr_eval/asr_eval.streaming.html))

- A base class and buffers for streaming models
- Streaming evaluation diagrams
