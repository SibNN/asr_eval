asr_eval
###################

This Python project is a set of tools for:

1. Evaluating multi-reference ASR (automatic speech recognition)
2. Running and evaluating non-streaming ASR, and perform a detailed error analysis
3. Running and evaluating streaming ASR, producing many informative diagrams

It can also serve as a streaming inference wrapper and a collection of ASR models and datasets.
